Soporte de AlertaRadar

AlertaRadar es una aplicación de asistencia para la conducción que puede mostrar la velocidad, avisar sobre radares configurados y ofrecer accesos rápidos a aplicaciones y acciones elegidas por el usuario.

Información útil para soporte

Para poder analizar mejor un problema, incluí cuando sea posible:

  • Modelo de celular.
  • Versión de Android.
  • Versión de AlertaRadar instalada.
  • Descripción del problema y pasos para reproducirlo.
  • Capturas de pantalla, si corresponde y es seguro obtenerlas.
  • Si el problema ocurre con la app en pantalla, en segundo plano o con el teléfono bloqueado.

Preguntas frecuentes

¿Por qué AlertaRadar necesita ubicación?

La ubicación se utiliza para calcular velocidad, detectar movimiento y determinar la proximidad a radares o puntos configurados. Para determinadas funciones de conducción, la aplicación puede mantener un servicio en primer plano cuando deja de estar visible.

¿Por qué aparece una notificación permanente mientras AlertaRadar está activa?

Android exige una notificación visible cuando una aplicación utiliza un servicio en primer plano para continuar realizando tareas como el monitoreo de ubicación. Esa notificación también permite al usuario saber que AlertaRadar continúa activa.

¿AlertaRadar puede funcionar con la pantalla bloqueada?

Las alertas de radar pueden continuar funcionando cuando el servicio de conducción está activo. Sin embargo, algunas marcas de celulares aplican restricciones adicionales de batería o de ejecución en segundo plano que pueden afectar este comportamiento.

¿AlertaRadar abre automáticamente otras aplicaciones mientras conduzco?

Android restringe la apertura automática de aplicaciones desde segundo plano o con el teléfono bloqueado. AlertaRadar puede mostrar avisos y accesos para que el usuario abra una aplicación configurada cuando el sistema lo permita.

¿Los radares están siempre actualizados?

No se puede garantizar que la información sea completa o esté actualizada en todo momento. AlertaRadar puede conservar una copia local para continuar funcionando sin conexión, por lo que el usuario debe respetar siempre la señalización vial vigente.

¿Qué hago si no recibo alertas?

Verificá que AlertaRadar tenga permiso de ubicación y notificaciones, que el monitoreo esté activo y que Android no esté restringiendo excesivamente la ejecución de la aplicación por ahorro de batería.

Seguridad durante la conducción

No configures ni manipules AlertaRadar mientras conducís. Realizá los ajustes antes de iniciar el viaje o con el vehículo detenido en un lugar seguro. La aplicación es una ayuda complementaria y no sustituye la atención del conductor ni la señalización y normativa de tránsito.
