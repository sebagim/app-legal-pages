Soporte de EjecuTAG

EjecuTAG es una app para configurar tags NFC y asociarlos a acciones simples, como abrir una aplicación instalada o abrir una URL.

Contacto

Si necesitás soporte, podés escribir a:

sguyapps@gmail.com

Información útil para soporte

Para poder ayudarte mejor, incluí en tu mensaje:

  • Modelo de celular.
  • Versión de Android.
  • Versión de EjecuTAG instalada.
  • Descripción del problema.
  • Capturas de pantalla, si corresponde.

Notas importantes

  • El celular debe tener NFC disponible para preparar y leer tags NFC.
  • Para ejecutar una acción al leer un tag, el celular debe estar desbloqueado.
  • La app debe estar activa, abierta en pantalla o en segundo plano.
  • Algunas marcas de celulares pueden aplicar restricciones de batería que afecten apps en segundo plano.
