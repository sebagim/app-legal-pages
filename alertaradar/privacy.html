Política de Privacidad de AlertaRadar

Última actualización: 2 de noviembre de 2026

Esta Política de Privacidad describe cómo AlertaRadar maneja la información necesaria para ofrecer funciones relacionadas con la conducción, la velocidad, la proximidad a radares y el acceso rápido a aplicaciones configuradas por el usuario.

1. Ubicación y velocidad

AlertaRadar utiliza la ubicación del dispositivo, incluida la ubicación precisa cuando el usuario concede ese permiso, para obtener datos de movimiento y velocidad, detectar situaciones de conducción y determinar la proximidad a radares o puntos configurados.

Cuando el usuario activa las funciones de monitoreo, AlertaRadar puede continuar utilizando la ubicación mientras la aplicación se encuentra en segundo plano o con la pantalla bloqueada mediante un servicio en primer plano de Android. Durante ese funcionamiento Android muestra una notificación persistente.

La ubicación utilizada para el monitoreo normal se procesa principalmente en el dispositivo. AlertaRadar no está diseñada para registrar ni enviar a un servidor un historial continuo de los desplazamientos del usuario.

2. Radares oficiales y personales

AlertaRadar puede descargar de Internet un listado de radares oficiales o públicos para almacenarlo localmente y utilizarlo posteriormente, incluso cuando no existe conexión a Internet.

El usuario también puede crear, modificar o eliminar radares personales. La información de esos radares puede incluir nombre, ubicación geográfica, sentido, velocidad máxima y puntos de aproximación. Esta información se almacena localmente en el dispositivo.

Si la aplicación ofrece una función para reportar o proponer información sobre un radar y el usuario decide utilizarla, los datos incluidos expresamente en ese reporte pueden enviarse a servicios de backend utilizados por AlertaRadar para su revisión. Esto puede incluir la ubicación y los datos descriptivos del radar reportado.

3. Aplicaciones instaladas y accesos rápidos

AlertaRadar puede consultar las aplicaciones visibles y ejecutables del dispositivo para permitir que el usuario seleccione aplicaciones que desea abrir desde el dashboard, como aplicaciones de navegación u otras aplicaciones compatibles.

La aplicación no utiliza esta información para crear perfiles del usuario ni la envía como una lista de aplicaciones instaladas a servidores propios.

4. Mensajes y llamadas configurados por el usuario

AlertaRadar puede guardar localmente mensajes predefinidos y números de teléfono configurados por el usuario para facilitar accesos rápidos a aplicaciones externas, como WhatsApp o la aplicación de teléfono.

AlertaRadar no envía mensajes de WhatsApp automáticamente ni realiza llamadas sin la intervención correspondiente del usuario. La aplicación prepara o abre la aplicación externa con la información configurada, según lo permitido por Android y por la aplicación de destino.

5. Preferencias y datos almacenados localmente

AlertaRadar puede almacenar en el dispositivo, entre otros datos:

  • Preferencias de funcionamiento y visualización.
  • Configuración de alertas, sonido, vibración y velocidad.
  • Aplicaciones seleccionadas para accesos rápidos.
  • Mensajes y números configurados por el usuario.
  • Radares personales y modificaciones locales sobre radares oficiales.
  • Copias locales del listado de radares descargado.
  • Estado local necesario para determinadas funciones Premium.

Estos datos se utilizan para proporcionar las funciones elegidas por el usuario. El usuario puede eliminarlos mediante las opciones disponibles en la aplicación, borrando los datos de la app desde Android o desinstalando AlertaRadar.

6. Compras dentro de la aplicación

AlertaRadar puede ofrecer funciones Premium mediante suscripción o compra única dentro de la aplicación.

Las compras son procesadas por Google Play. AlertaRadar no almacena directamente números de tarjeta, datos bancarios ni credenciales de pago. Google Play puede procesar información necesaria para gestionar la compra, suscripción, restauración y estado de las prestaciones adquiridas conforme a sus propias políticas.

7. Servicios de terceros

AlertaRadar puede utilizar servicios de terceros necesarios para su funcionamiento, incluyendo:

  • Google Play: distribución de la aplicación y gestión de compras dentro de la app.
  • Firebase: funciones técnicas como configuración remota y, cuando corresponda, procesamiento de reportes o códigos promocionales.
  • GitHub Pages: distribución de archivos públicos con información de radares.
  • Servicios de mapas: para mostrar cartografía dentro de las funciones de mapa de la aplicación.

Estos proveedores pueden procesar información técnica necesaria para prestar sus servicios, como dirección IP, información del dispositivo o datos de la solicitud, de acuerdo con sus propias políticas de privacidad.

8. Permisos utilizados

  • Ubicación precisa o aproximada: para velocidad, conducción, mapas y alertas de proximidad.
  • Notificaciones: para informar sobre el funcionamiento de la app y mantener visible el servicio en primer plano cuando corresponda.
  • Vibración: para alertas configuradas por el usuario.
  • Acceso a Internet: para actualizar información de radares y acceder a servicios necesarios.
  • Visibilidad de aplicaciones compatibles: para permitir seleccionar y abrir aplicaciones desde AlertaRadar.

9. Seguridad

Se aplican medidas razonables para limitar el tratamiento de datos a lo necesario para las funciones de la aplicación. La información local queda además sujeta a los mecanismos de seguridad del dispositivo, como bloqueo de pantalla, PIN, contraseña o biometría.

10. Conservación y eliminación de datos

Los datos almacenados localmente permanecen en el dispositivo mientras sean necesarios para las funciones configuradas o hasta que el usuario los elimine. La desinstalación de la aplicación normalmente elimina los datos locales asociados, sin perjuicio de información que Android, Google Play u otros proveedores puedan conservar conforme a sus propias políticas.

Los datos que el usuario envíe voluntariamente a un servicio remoto, por ejemplo un reporte sobre un radar, pueden conservarse durante el tiempo necesario para revisar, administrar y mantener la calidad de esa información. Para solicitar información sobre esos datos o su eliminación, el usuario puede utilizar el correo de contacto indicado al final de esta política.

11. Privacidad de menores

AlertaRadar está orientada a funciones relacionadas con la conducción y no está dirigida específicamente a menores de edad. No se recopila intencionalmente información personal de menores para fines publicitarios o de elaboración de perfiles.

12. Uso durante la conducción

AlertaRadar es una herramienta de asistencia y no sustituye la atención del conductor, la señalización vial ni el cumplimiento de las normas de tránsito. La información sobre radares puede contener errores, estar incompleta o quedar desactualizada. El usuario debe evitar manipular el dispositivo mientras conduce.

13. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando cambien las funciones de la aplicación, los servicios utilizados o los requisitos legales y de las tiendas de aplicaciones. La versión vigente se publicará en esta misma página.
