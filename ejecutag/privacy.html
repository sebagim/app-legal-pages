Política de Privacidad de EjecuTAG

Última actualización: 27 de mayo de 2026

Esta Política de Privacidad describe cómo EjecuTAG maneja la información dentro de la aplicación. EjecuTAG es una app diseñada para configurar tags NFC y asociarlos a acciones simples, como abrir una aplicación instalada o abrir una dirección web.

1. Información que recopila la app

EjecuTAG no recopila, vende ni comparte datos personales del usuario con terceros.

La app guarda localmente en el dispositivo la información necesaria para funcionar, como:

  • Nombre asignado a cada tag.
  • Acción configurada para cada tag.
  • URL configurada por el usuario, si corresponde.
  • Identificador técnico del tag NFC preparado.
  • Estado de configuración de la app.
  • Estado Premium local, cuando corresponda.

Esta información se almacena en el propio dispositivo y se utiliza únicamente para permitir el funcionamiento de la app.

2. Uso de NFC

EjecuTAG utiliza NFC para preparar tags físicos y para ejecutar la acción configurada cuando el usuario acerca el celular al tag.

La app no utiliza NFC para rastrear al usuario ni para recopilar información personal.

3. Consulta de aplicaciones instaladas

EjecuTAG puede consultar aplicaciones instaladas en el dispositivo para permitir que el usuario seleccione qué app desea abrir mediante un tag NFC.

Esta información se usa únicamente dentro de la app para mostrar opciones al usuario y no se envía a servidores externos.

4. URLs configuradas por el usuario

El usuario puede configurar tags para abrir direcciones web o enlaces compatibles. Esas URLs se guardan localmente para ejecutar la acción elegida por el usuario.

5. Compras dentro de la app

EjecuTAG puede ofrecer funciones Premium mediante compras dentro de la app, como pago único o suscripción mensual.

Las compras son procesadas por Google Play. EjecuTAG no almacena datos de tarjetas, medios de pago ni información bancaria.

6. Permisos utilizados

EjecuTAG puede solicitar o utilizar los siguientes permisos:

  • NFC: para preparar y leer tags NFC.
  • Consulta de apps instaladas: para permitir seleccionar una app a abrir.

EjecuTAG no solicita ubicación, cámara, micrófono, contactos ni acceso a archivos personales para su funcionamiento principal.

7. Servicios de terceros

La app utiliza servicios de Google Play para gestionar compras dentro de la app. El uso de estos servicios está sujeto a las políticas de privacidad de Google.

8. Seguridad

La información de configuración se guarda localmente en el dispositivo. Si el usuario desinstala la app o borra sus datos, esa información puede eliminarse.

9. Privacidad de menores

EjecuTAG no está dirigida específicamente a menores de edad y no recopila intencionalmente información personal de menores.

10. Cambios en esta política

Esta Política de Privacidad puede actualizarse ocasionalmente. Cualquier cambio será publicado en esta misma página.
